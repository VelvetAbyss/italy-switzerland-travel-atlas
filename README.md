# 意大利 × 瑞士旅行探索地图

[打开在线地图](https://velvetabyss.github.io/italy-switzerland-travel-atlas/)

静态旅行灵感地图，收录 98 个地点、85 份城市与城镇介绍，以及 39 条铁路连接和 137 个车站。支持城市与季节筛选、地点攻略、铁路示意、收藏和导出；以 1 月旅行作为冬季参考情景。

直接打开 `index.html`，或使用 GitHub Pages 静态托管。初次加载需网络；地理底图和主要铁路连接已包含在页面中。街道底图及外部资料需要联网。

铁路为主要客运连接示意，不是精确轨迹、完整路网或实时班次；连线不代表直达或每站停靠。开放、交通与票价请以实际出行日官方资料为准。

图片分别遵循各自许可，作者、许可及原图链接保留在对应地点详情中；图片文件仅从内嵌数据解码，未改变像素。本仓库不对第三方图片授予统一许可。Leaflet 使用 BSD 2-Clause 许可证，见 `LICENSE-Leaflet-1.9.4.txt`；国家边界来自公共领域 Natural Earth，在线街道底图归属 OpenStreetMap 贡献者。
